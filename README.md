The goal is to strengthen C++ programming skills and develop a deeper understanding of object-oriented programming concepts through hands-on practice.

## Contents

* Weekly lab assignments
* C++ programming exercises
* Object-oriented programming concepts
* Practice with classes, objects, and operator overloading

## Language

* C++

The directory structure above is an example. Actual directory names may vary.

## How to Compile and Run

Compile a C++ source file using g++:

g++ -std=c++17 main.cpp -o main

Run the compiled program:

./main

Replace main.cpp with the appropriate source file for each assignment.
